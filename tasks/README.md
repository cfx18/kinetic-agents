## 使用边界

- T01/T03/T10已具备父机理输入；其他类型仍需基线、候选、原始文献或检查点等材料，见清单。
- 配置格式与现有任务一致，不等于已经可以启动：当前runner校验既有TASK哈希，并强制接终点评测及机理提交协议。新的开放任务（含只交研究报告的类型）尚未接入这些运行协议。
- 新配置使用各任务独立、尚不存在的local/task_qualification目录，绝不自动借用旧任务资格或旧610评测。没有伪造accepted文件，也没有把旧分数充当GT。
- 保留原启动保护；本轮不扩展为无grader运行器开发。不启动计算。资源数字沿用模板，不代表新增预算获批。
- 旧usc_ii与usc_ii_expert_v2输入和运行配置未修改。新增文件仅在本地release checkout，未commit/push。
