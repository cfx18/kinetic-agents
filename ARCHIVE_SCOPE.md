# Results-only distribution scope

This edition contains real recorded outcomes, not recreated Agent trajectories.
The owner selected a smaller result archive. Raw logs remain locally retained
and are not distributed; no fabricated or synthetic evidence substitutes for them.

## Included

- Original runtime/scientific source, task variants and configuration examples.
- USC-II parent, experimental observations, uncertainty/units and the historically
  exposed 610-case evaluation pool (491 development + 119 historical recheck).
- All 18 run identities and one repair snapshot, including cancelled and unfinished
  entries; captured configuration, submission and terminal status where available.
- Locked submitted artifacts and original independent endpoint files: mechanism
  files, scoring contracts, per-case predictions/errors/failures and scorecards.
- The original dated research report, tables, figures and analysis scripts, plus
  historical research notes. Original scientific evidence bytes are unchanged.
- Small frozen evaluator-source TAR files at endpoints: these identify the actual
  evaluated code, not remote dependency/install bundles or model transcripts.

## Not distributed

Raw model/tool transcripts, step-by-step process pages, research session databases,
search intermediate results, recovery logs, remote transfer/install packages and
large intermediate numerical fields. Host acceptance/diagnostic snapshots and
unrelated post-training task packs are also outside this result edition.
No full-run Release assets, host credentials or old repository Git history are
included. The original full local archive has not been deleted or overwritten.

## How to interpret the evidence

Run README/ARCHIVE indexes and `results/` summaries are generated navigation,
not model-authored logs. Existing RUN_REPORTs, submitted reports and research notes
are historical material: local absolute paths and references to omitted logs may
not resolve in this edition. A historical claim that logs were captured is not a
claim they are supplied here. Process-based interpretations cannot be fully audited
from this package alone. No end-to-end replay or complete cost/decision audit is promised.

The original report retains its 10-endpoint/30-candidate/18,300-row cutoff. Later
captured endpoint files are listed separately, without silently revising that report.
Missing or failed cases remain missing or failed; successful-subset error is not
presented as a full-pool score. These observations are not a pristine blind test,
and endpoint performance does not establish RSI, decision causality or general
model superiority.

`results/files.json` records supplied bytes and provenance. Hashes detect changes
relative to that index, not independently authenticate the experiment's history.
Do not feed this answer-containing archive into a new clean search Agent.

Private storage is not public redistribution clearance. MIT covers original code
only; see [data rights](research/DATA_RIGHTS.md). Publication does not authorize a
new model request, cluster job or purchase.
